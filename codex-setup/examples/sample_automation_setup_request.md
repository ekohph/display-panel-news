# Sample Automation Setup Request

Paste this into Codex after downloading this repository or copying `codex-setup/` into a repository.

```text
I am not familiar with Codex automations.

Please read codex-setup/README.md and codex-setup/prompts/setup_automation_ko.md, then guide me through setting up a recurring public display-panel news briefing automation.

Defaults:
- Output: Markdown only
- Email: off
- Commit/push: ask me first
- Sunday research coverage: on for Sunday runs
- Privacy: do not infer or mention my employer or affiliation
- Discovery: use Google News RSS from codex-setup/reference/search_queries.md, then cite original publisher URLs
- Exclusions: do not include wikileaks-kr.org unless explicitly requested and strongly corroborated

Ask me for the schedule and timezone, then use the Codex automation capability if it is available in this session.
```
